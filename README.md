# FITNESS CLUB — Razor Pages

Веб-приложение для управления фитнес-клубом, разработанное с использованием ASP.NET Core Razor Pages и .NET 10.

## Основные возможности

- Просмотр списка участников клуба.
- Добавление новых участников.
- Просмотр подробной информации об участниках.
- Удаление участников.
- Просмотр информации о тренерах и абонементах.
- Валидация вводимых данных.

## Используемые технологии

- C#
- ASP.NET Core Razor Pages
- .NET 10
- HTML, CSS, Bootstrap
- Docker
- Git

## Запуск проекта

Для локального запуска:

```bash
dotnet run
```

Для сборки Docker-образа:

```bash
docker build -t fitness-club-wt5 .
```

Для запуска контейнера:

```bash
docker run --rm -p 8080:10000 fitness-club-wt5
```

После запуска приложение доступно по адресу http://localhost:8080.
